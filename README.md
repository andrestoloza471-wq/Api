# 🚀 API 

Este proyecto eta construyendo una **API** desde cero con **.NET 9**. Es una herramienta sencilla pero robusta para gestionar una lista de tareas pendientes.

## 🧐 ¿Qué hace este proyecto?
Esta API permite organizar actividades de forma digital. A través de ella puedes:
* **Consultar:** Ver la lista completa de tareas.
* **Crear:** Añadir nuevas tareas con un título específico.
* **Estructura:** El código no está amontonado; está dividido en capas (Modelos, Servicios y Controladores) para que sea fácil de entender y mejorar.

## 🛠️ Tecnologías utilizadas
* **Lenguaje:** C# con el framework .NET 9 (lo más nuevo de Microsoft).
* **Interfaz:** Swagger (Swashbuckle), que genera una página visual para probar la API sin instalar programas extra.
* **Patrones:** Inyección de Dependencias (para un código más limpio y escalable).

## 🚀 Cómo ponerlo en marcha

Si quieres probar este proyecto en tu propia PC, sigue estos pasos:

1.  **Requisitos:** Tener instalado el [SDK de .NET 9](https://dotnet.microsoft.com/download).
2.  **Clonar/Descargar:** Baja este repositorio a una carpeta local.
3.  **Ejecutar:** Abre una terminal en la carpeta del proyecto y escribe:
    ```bash
    dotnet run
    ```
4.  **¡A explorar!:** Cuando veas que el servidor ha arrancado, abre tu navegador y ve a:
    [http://localhost:5146/swagger]
